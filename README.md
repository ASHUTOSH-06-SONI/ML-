ML

This repository/document is focused on covering important machine learning research papers in depth, along with revising and understanding every core concept involved. It serves both as a revision resource and a structured starting point for deeper exploration.

Papers and Concepts
1. Transformers

Paper: https://arxiv.org/abs/1706.03762

Core Concepts:

Multi-head self-attention
Positional encoding
Encoder-decoder architecture
Masking (causal + padding)
Query, Key, Value projections
Scaled dot-product attention
Softmax stability tricks
Residual connections and LayerNorm
Parallelization vs recurrence
2. BERT

Paper: https://arxiv.org/abs/1810.04805

Core Concepts:

Masked Language Modeling (MLM)
Next Sentence Prediction (NSP)
Fine-tuning pipeline
Bidirectional context
Tokenization (WordPiece / BPE)
Transfer learning in NLP
Pretrain vs finetune gap
Representation learning
3. ResNet

Paper: https://arxiv.org/abs/1512.03385

Core Concepts:

Residual blocks
Skip connections
Basic CNN backbone
Vanishing gradients problem
Identity mapping
BatchNorm behavior
Optimization of deep networks
4. GAN

Paper: https://arxiv.org/abs/1406.2661

Core Concepts:

Generator and Discriminator loop
Alternating optimization
Minimax optimization
Mode collapse
Training instability
Loss function design
5. Diffusion Models

Paper: https://arxiv.org/abs/2006.11239

Core Concepts:

Forward noise process
Reverse denoising model
Sampling loop
Markov chains
Gaussian noise schedules
Score matching
Variational inference intuition
